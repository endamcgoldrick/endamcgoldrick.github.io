The problem

My day job is Entra ID, Intune and Autopilot on a live tenant, where every change affects real people. That is the wrong place to try a setting for the first time or to find out what breaks.

I wanted a tenant where nothing depends on the result, set up from an empty start, with the steps written down so I can repeat them and explain them.

What I built

A runbook for a free Microsoft 365 developer or trial tenant. It covers:

  • Users and groups in Entra ID.
  • MFA through Conditional Access, starting in report-only mode, with a break-glass account excluded so I can't lock myself out.
  • Intune enrolment for Windows and for macOS.
  • A compliance policy, a configuration profile and an app deployment.
  • A test table: what I did, what I expected and what happened.

How I built it

The runbook goes in the order you would do it in a new tenant: identities first, then access rules, then devices. Conditional Access starts in report-only mode, so I can see what a policy would have blocked before it blocks anything.
